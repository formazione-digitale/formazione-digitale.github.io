Configurare VS Code per C++

Installazione passo per passo di Visual Studio Code e del compilatore g++ su Windows — con MSYS2 e MinGW-w64 UCRT64, dalla prima riga alla prima compilazione.

💻 Windows 10 / 11 📷 12 screenshot ⏰ ~30 min 🔦 Gratuito ⬇ Scarica guida Word

Prerequisiti VS Code & MSYS2 PATH & verifica Estensione & Hello World
00 — Prima di iniziare

Prerequisiti

Non è richiesta alcuna conoscenza preliminare di C++. Servono solo un PC Windows e una connessione internet. Verifica di avere tutto prima di procedere.

💻
Sistema operativo Windows 10 o 11, versione a 64-bit
🌐
Connessione internet VS Code ~100 MB · MSYS2 ~100 MB
🔑
Diritti amministratore Necessari per installare i programmi
⏱️
Tempo 25–35 min (dipende dalla connessione)

Software da scaricare

⬇️ Visual Studio Code code.visualstudio.com ⬇️ MSYS2 msys2.org
📌 Perché MSYS2 e non altri approcci? MSYS2 usa la variante UCRT64 (Universal C Runtime), compatibile con Windows 10/11 moderni. Fornisce il gestore di pacchetti pacman per installare e aggiornare g++, gdb e make esattamente come su Linux.
01–03 — Installazione

VS Code e MSYS2

1 — Installare Visual Studio Code

VS Code è un editor di codice open-source sviluppato da Microsoft. È gratuito, leggero e supporta decine di linguaggi.

  1. Vai su code.visualstudio.com e clicca su "Download for Windows".
  2. Avvia il file scaricato (VSCodeSetup-x64-*.exe) e segui l'installazione guidata.
  3. Nella schermata "Select Additional Tasks" seleziona:
    • ✅ Add "Open with Code" to Windows Explorer file context menu
    • ✅ Add "Open with Code" to Windows Explorer directory context menu
    • ✅ Register Code as an editor for supported file types
  4. Clicca Install e attendi il completamento.
Figura 1 — Pagina ufficiale VS Code: pulsante di download per Windows

2 — Installare MSYS2

MSYS2 è l'ambiente che porta su Windows il toolchain di compilazione GNU, incluso il gestore di pacchetti pacman.

  1. Vai su msys2.org e scarica l'installer (msys2-x86_64-*.exe).
  2. Avvia l'installer e mantieni il percorso predefinito C:\msys64.
  3. Al termine dell'installazione lascia attiva la spunta "Run MSYS2 now" e clicca Finish.
Figura 2 — Lascia la spunta attiva: si aprirà subito il terminale MSYS2 UCRT64
💡 Quale terminale si apre? Si aprirà il terminale MSYS2 UCRT64, riconoscibile dal prompt colorato. È il terminale corretto per il passaggio successivo.

3 — Installare g++, gdb e make

Nel terminale MSYS2 UCRT64 appena aperto, installa l'intero toolchain con un solo comando:

MSYS2 UCRT64 — terminale 
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
  1. Alla domanda "Enter a selection (default=all)" → premi Invio.
  2. Alla domanda "Proceed with installation? [Y/n]" → digita Y e premi Invio.
  3. Attendi il completamento del download (qualche minuto).
  4. Verifica l'installazione con i tre comandi seguenti, uno alla volta:
Verifica — MSYS2 UCRT64 
g++ --version
gdb --version
make --version
Figura 3 — Ogni comando mostra la versione installata: l'installazione è riuscita
04–05 — Configurazione

PATH e verifica

4 — Aggiungere g++ al PATH di Windows

Windows non sa ancora dove trovare g++. Dobbiamo aggiungere C:\msys64\ucrt64\bin alla variabile di sistema Path — l'elenco delle cartelle in cui Windows cerca i programmi eseguibili.

  1. Premi Win e digita variabili d'ambiente. Clicca su "Modifica le variabili d'ambiente del sistema".
  2. Nella finestra "Proprietà del sistema" clicca su "Variabili d'ambiente…".
Figura 4 — Proprietà del sistema → "Variabili d'ambiente…"
  1. Nella sezione Variabili di sistema (in basso), seleziona Path e clicca "Modifica…".
Figura 5 — Seleziona "Path" nelle variabili di sistema → "Modifica…"
  1. Clicca "Nuovo" e inserisci esattamente:
Percorso da aggiungere 
C:\msys64\ucrt64\bin
Figura 6 — Aggiungi C:\msys64\ucrt64\bin come nuova voce nella variabile Path
  1. Clicca OK su tutte le finestre aperte.
⚠️ RIAVVIA IL PC ORA Le modifiche alle variabili d'ambiente sono attive solo dopo il riavvio. Salva tutto e riavvia prima di andare avanti.

5 — Verificare l'installazione

Dopo il riavvio, apri il Prompt dei comandi (Win+R → cmd → Invio) e lancia:

Prompt dei comandi — verifica finale 
g++ --version
gdb --version
Figura 7 — Output corretto: g++ è riconosciuto dal Prompt dei comandi di Windows
💡 Il comando non viene riconosciuto? Controlla che C:\msys64\ucrt64\bin sia nella variabile di sistema Path (non utente), che MSYS2 sia installato in C:\msys64 e che tu abbia riavviato il PC dopo aver modificato il PATH.
06–07 — VS Code C++

Estensione C/C++ e Hello, World!

6 — Installare l'estensione C/C++

VS Code è un editor generico. L'estensione ufficiale Microsoft aggiunge IntelliSense, evidenziazione della sintassi e supporto al debugger.

  1. Apri VS Code.
  2. Clicca sull'icona Extensions nella barra sinistra o premi Ctrl+Shift+X.
  3. Cerca C/C++ e installa l'estensione di Microsoft (la prima, con milioni di download).
Figura 8 — Installa "C/C++" di Microsoft dal Marketplace di VS Code
Figura 9 — L'estensione è installata e pronta

7 — Hello, World!

Creiamo il primo programma C++. Crea una cartella dedicata (es. C:\progetti-cpp), aprila con File → Apri cartella… in VS Code e crea un file hello.cpp.

Al primo utilizzo VS Code potrebbe chiedere di selezionare il compilatore:

Figura 10 — Seleziona "Use g++.exe Found at C:/msys64/ucrt64/bin/"
Figura 11 — VS Code è configurato per C++ e pronto alla scrittura

Scrivi il codice nel file hello.cpp:

C++ · hello.cpp 
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

Apri il terminale integrato (Ctrl+`) e compila:

Terminale VS Code — compila ed esegui 
g++ hello.cpp -o hello
.\hello
Figura 12 — Il programma viene compilato ed eseguito: l'output è "Hello, World!"
🎉 Fatto! L'ambiente di sviluppo C++ è pronto. Per i progetti successivi aggiungi sempre -Wall -std=c++17 alla compilazione:
Compilazione consigliata 
g++ hello.cpp -o hello -Wall -std=c++17

# -Wall   → attiva tutti gli avvisi del compilatore (sempre consigliato)
# -std=c++17 → usa lo standard C++17 (raccomandato per nuovi progetti)

Riepilogo — checklist finale

  • VS Code installato e avviabile
  • MSYS2 installato in C:\msys64
  • g++, gdb e make installati tramite pacman
  • C:\msys64\ucrt64\bin aggiunto alla variabile di sistema Path
  • PC riavviato dopo la modifica al PATH
  • g++ --version riconosciuto nel Prompt dei comandi
  • Estensione C/C++ di Microsoft installata in VS Code
  • hello.cpp compilato ed eseguito correttamente
